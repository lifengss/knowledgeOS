# 第7章 项目 Wiki：把 PRD/需求变成可读文档

比起在文件里翻找，KS 把 PRD、需求等源文档渲染成带目录、可跳转的 **项目 Wiki**。本章讲解如何阅读与导航。

## Wiki 页面布局

进入 **项目 Wiki** 页，分为左右两栏：

- **左侧索引**：按分组列出文档——
  - `prd`（产品需求）、`req`（功能需求）、`api`（接口）、`其它`；
  - **实体（GBrain 抽取）** 分组：由第8章的实体抽取生成；
  - **API 调用依赖（列表）**：可一键在图谱中查看。
- **右侧正文**：选中条目后的 Markdown 渲染结果。

![Wiki 索引](/tutorial/assets/wiki-index.png)

> 图7-1 项目 Wiki 索引：按分组列出文档，并包含实体分组与 API 依赖入口。

## 页面内目录与 wikilink

打开一篇文档后，正文顶部有**页面内目录**（基于文档中的 H2/H3 标题生成），点击可跳转。

文档内若出现 `[[文档名]]` 形式的 **wikilink**，会被渲染为可点击链接，跳转到对应文档。

![Wiki 详情](/tutorial/assets/wiki-detail.png)

> 图7-2 Wiki 详情：顶部页面内目录 + 正文 Markdown 渲染，支持 wikilink 跳转。

## 案例：打开 PRD 并顺着目录阅读

1. 进入 **项目 Wiki**，在左侧 `prd` 分组找到目标 PRD（如「LLM_sim概要设计」）；
2. 点击打开，右侧显示正文；
3. 用顶部目录跳到「整体架构」小节；
4. 遇到 `[[功能开发列表]]` 这样的 wikilink，点击直接跳到对应需求文档。

> 提示：从 Wiki 的「API 调用依赖（列表）」点 **在图谱中查看**，可跳转到图谱页并聚焦该模块的 API 依赖。

## 小结

- Wiki 把原始文档变成带目录、可跳转的可读页面；
- 左侧分组索引 + 页面内目录 + wikilink 三层导航；
- 与图谱联动，便于从文档直达接口依赖视图。
