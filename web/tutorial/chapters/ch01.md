# 第1章 快速上手：认识知识管理系统

本章带你第一次打开 KS，认识它的整体界面，并学会切换项目。读完你应能独立进入任意一个功能模块。

## 界面总览

KS 是一个**单页 Web 应用**，整体分为三块：

- **顶栏**：系统标题、当前项目标签与项目下拉、导入按钮、运行按钮。
- **左侧导航**：12 个功能模块的入口。
- **主内容区**：随所选模块变化，展示对应功能。
- **帮助区**：左侧导航底部独立分区，放置「使用教程」入口。

> 图1-1 知识管理系统概览页：左侧为功能导航，右侧为当前项目的健康度概览。

## 12 个功能模块

左侧导航依次为：

| 模块 | 说明 |
|------|------|
| 概览 | 当前项目健康度一览 |
| 知识库 | 浏览已沉淀的结构化知识 |
| 项目 Wiki | 把 PRD/需求渲染为可读文档 |
| 草稿箱 | 待审核的导入/编辑草稿 |
| 冲突处理 | 解决知识冲突 |
| 图谱 | API 依赖与实体关系可视化 |
| 业务流程 | 业务知识图谱 |
| 知识问答 | 用自然语言查询知识 |
| 审计日志 | 追踪每一次知识变更 |
| 质量监控 | 知识类型覆盖与趋势 |
| 接口文档 | 系统对外 REST API 清单 |
| 系统设置 | 对接 AI 平台与配置 GBrain |

> 「使用教程」作为帮助入口，独立在左侧导航下方的帮助区，与功能模块视觉区分。

## 案例 1：首次打开，认识界面

1. 在浏览器打开 KS 地址（默认 `http://localhost:3000`）。
2. 默认进入 **概览** 页，右侧展示当前项目的统计卡片（知识条目数、草稿数、冲突数等）。
3. 把鼠标移到左侧每个导航项上，了解它们的名称；点击任意一项，主内容区会切换。

> 提示：所有模块都基于「当前项目」工作。切换项目会改变知识库、草稿、图谱等全部数据范围。

## 案例 2：切换到「AI计算集群仿真系统」项目

不同项目拥有**相互隔离**的知识库。我们以示例项目 `tg-yja078186`（名称「AI计算集群仿真系统」）为例：

1. 在顶栏找到**项目下拉框**（显示当前项目名）。
2. 点击下拉，选择 **AI计算集群仿真系统**。
3. 页面会自动刷新，左上角项目标签变为该项目名，知识库/草稿等也随之切换。

![项目切换](/tutorial/assets/project-switch.png)

> 图1-2 在顶栏项目下拉中切换项目，所有数据范围随项目变化。

## 小结

- KS 是单页应用，左侧 12 个功能模块 + 顶栏项目切换 + 帮助区「使用教程」构成主要操作入口。
- 一切数据都绑定到「当前项目」，切换项目即切换知识空间。
