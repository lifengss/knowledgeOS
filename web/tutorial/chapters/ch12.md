# 第12章 系统设置：对接 AI 平台与配置 GBrain

KS 的 AI 能力（生成、实体抽取、摘要）依赖外部模型服务。本章讲解在 **系统设置** 中完成对接与配置。

## 设置页结构

进入 **系统设置** 页，配置分为两组：

- **AI 平台对接（ai 段）**：系统生成类能力所用的 AI 平台；
- **GBrain 大模型（gbrain 段）**：实体抽取与 AI 摘要所用的模型。

配置持久化到 `data/ai_config.json`。

![系统设置](/tutorial/assets/settings.png)

> 图12-1 系统设置页：AI 平台对接 与 GBrain 大模型 两组配置。

## AI 平台对接（ai 段）

| 字段 | 说明 |
|------|------|
| endpoint | AI 平台服务地址 |
| model | 生成所用模型 |
| apiKey | 平台密钥（写入 `data/`，已被 .gitignore 忽略，不会入库） |

该组用于导入抽取、问答生成等需要「生成」能力的场景。

## GBrain 大模型（gbrain 段）

| 字段 | 说明 |
|------|------|
| endpoint | 模型服务地址（如 `https://api.icompify.com/v1`） |
| model | 抽取/摘要所用模型（如 `minimax-m3`） |

> 第8章的「抽取实体」「生成 AI 摘要」即调用此处配置的模型。未配置时相关操作会返回错误，请先在此填好 endpoint 与 model。

## 案例：配置 GBrain 以启用实体抽取

1. 进入 **系统设置**；
2. 在 **GBrain 大模型** 组填写 endpoint 与 model；
3. 点击 **保存**；
4. 回到项目 Wiki 的 PRD 详情，点 **抽取实体**，即可正常生成实体页（见第8章）。

> 安全提示：`data/` 目录含 apiKey，已被 `.gitignore` 忽略；推送到 Git 时不会泄露密钥。

## 小结

- 系统设置分 AI 平台（生成）与 GBrain（抽取/摘要）两组；
- 配置落盘到 `data/ai_config.json`，密钥不入库；
- 配好 GBrain 后，第8章的智能增强才能真正生效。
