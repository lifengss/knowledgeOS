# 第5章 草稿审核与人工编辑优化

系统自动抽取的知识并非总是完美。KS 提供「草稿箱 + 人工编辑」链路，让人在 AI 产出之上做**可控的优化**，且每一步都可追溯。

## 两类草稿来源

- **导入草稿**：第3章导入后生成的待入库知识；
- **编辑草稿**：在知识库里手动修改一条知识时生成。

进入 **草稿箱** 页可看到所有待处理草稿。

![草稿箱](/tutorial/assets/drafts.png)

> 图5-1 草稿箱：列出当前项目的待审核草稿，含类型、来源与状态。

## 人工编辑优化的闭环

KS 的编辑不是「直接改盘」，而是生成**编辑草稿**进入审核流，保证可追溯、可回退：

1. 在 **知识库** 打开一条知识详情；
2. 点击 **编辑**，修改内容，并可**重分类移动**（选择新分类，系统会写新分类文件并删除原文件）；
3. 保存后，系统生成两条 L2 草稿：
   - **知识修改草稿**（`knowledge_edit`）：记录旧内容与新内容，入库时写回原仓库页面（所见即所得，不包 frontmatter）；
   - **质量规则草稿**（`quality_rule`）：由新旧对比提炼出可复用的质量规则，落库到 `quality-rules`。
4. 草稿进入草稿箱，等待确认提交。

![知识库详情中的编辑](/tutorial/assets/brain.png)

> 图5-2 在知识库详情中编辑并触发重分类移动，会生成可审核的编辑草稿。

## 案例：编辑一条知识并重分类移动

1. 知识库页打开一条「缺陷经验」；
2. 点 **编辑**，把内容补充更规范，并把分类改为「质量规则」；
3. 保存 → 草稿箱出现一条 `knowledge_edit` 与一条 `quality_rule`；
4. 在草稿箱选中这两条，点击 **提交**，内容写回知识库、质量规则入库。

> 提示：提交同样经过质量门控。若内容过短或来源可信度低，可能被拒并保留为「待处理」，可修改后重提。

## 为什么用草稿而不是直接写盘

- **可追溯**：每次修改都有草稿记录，审计日志可查；
- **可回退**：提交前可丢弃，不污染知识库；
- **可协作**：多人修改汇到草稿箱统一审核，避免相互覆盖。

## 小结

- 人工优化通过「编辑 → 生成草稿 → 提交」闭环完成；
- 重分类移动会写新分类并删原文件，保持分类一致；
- 一切改动经草稿箱审核与质量门控入库。
