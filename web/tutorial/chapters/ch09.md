# 第9章 图谱可视化：看清知识与接口的关联

当知识条目变多，仅靠列表难以看出彼此关系。KS 的 **图谱** 页用**力导向图**把知识与接口的依赖、实体关系可视化。本章讲解两种模式。

## 两种图谱模式

图谱页顶部有 **模式切换 Tab**：`api`（API 依赖）与 `entity`（实体图谱）。

![图谱 · API 依赖模式](/tutorial/assets/graph-api.png)

> 图9-1 API 依赖模式：节点为模块/接口，连线表示依赖关系。

### API 依赖模式（api）

- 每个节点代表一个模块或接口，按**域（domain）着色**；
- 连线为依赖关系（曲线带箭头）；
- **悬停**某节点会高亮其邻居，淡化无关节点；
- **点击**节点弹出详情面板；
- 支持**搜索**定位节点、**缩放/平移/拖拽**布局、图例说明。

### 实体图谱模式（entity）

切换到 `entity` 后，图由文档中抽取的**实体**构成：

- 节点 = PRD/需求文档中的实体（来自第8章的 GBrain 抽取与确定性解析）；
- 边类型：
  - `contains`：文档 → 其包含实体；
  - `related`：同一文档内共现的实体互连；
  - `ref`：文档间通过 `[[wikilink]]` 引用形成的关联。

![图谱 · 实体模式](/tutorial/assets/graph-entity.png)

> 图9-2 实体图谱模式：展示文档与实体的包含、共现、引用关系。

## 案例 1：查看某模块的 API 依赖

1. 进入 **图谱**，确认处于 `api` 模式；
2. 在搜索框输入模块名，定位节点；
3. 悬停节点观察其上下游依赖；
4. 点击节点查看详情面板中的调用关系。

## 案例 2：切换到实体图谱

1. 点击顶部 Tab 切到 `entity`；
2. 等待实体节点加载（来自项目 Wiki 的实体分组）；
3. 拖拽布局、点击实体查看其定义与关联文档。

> 提示：从 **项目 Wiki** 的「API 调用依赖（列表）」点 **在图谱中查看**，可直接跳到 api 模式并聚焦该模块及其邻居。

## 小结

- 图谱提供 api / entity 两种视角；
- api 模式看接口依赖，entity 模式看文档与实体关系；
- 悬停高亮、点击详情、搜索与拖拽让复杂关联一目了然。
