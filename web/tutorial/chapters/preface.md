# 前言 · 关于本教程

欢迎使用 **知识管理系统（KS, Knowledge System）** 使用教程。

本教程以「分章节、分案例」的方式，带你从零认识 KS，并逐步掌握它的核心能力：把 PRD、代码、缺陷等**源数据**沉淀为**结构化知识**，再借助 AI 抽取实体、生成摘要、可视化关联，最终用自然语言问答消费这些知识。

## 教程的版本机制

教程采用 `主版本.次版本` 的编号（例如 `1.0.0`）：

- **主版本随系统**：当 KS 系统升级到大版本（如从 `V1.0` 到 `V2.0`）时，教程主版本同步进位（`1.x` → `2.0.0`），并据此全面复核内容。
- **次版本独立迭代**：在不升级系统时，教程自身的纠错、补图、措辞优化只递增次版本（如 `1.0.0` → `1.0.1`），不影响主版本。

每一章都标注了所复核对应的系统版本（`reviewedSystem`）。进入教程页时，系统会自动比对当前 KS 版本与教程基准版本：

- 版本一致 → 正常阅读；
- 版本不一致 → 页面顶部出现**橙色横幅**，提示「系统已升级，本教程待复核」。

> 横幅只是提醒，不影响阅读。系统升级后，维护者会对照教程清单逐章复核、更新内容与截图，并 bump 教程版本号。

## 关于截图

教程中的图片均为**真实的网页快照**（在 KS Web UI 上实际截取），用于还原操作界面与预期效果。你看到的就是系统里真实的样子。

## 如何阅读

1. 在 KS 左侧导航点击 **「使用教程」**，进入教程页。
2. 左侧为**章节目录**，点击任一章节即可在右侧阅读；当前章节会高亮。
3. 右侧正文顶部有**页面内目录**（点击可跳转），正文中的图片可点击放大查看。
4. 章节之间相互独立，可按需跳读，不必从头到尾顺序阅读。

## 反馈

如果某处描述与实际界面不符，或你有希望补充的案例，请在系统内提交反馈，或联系知识库维护者更新教程清单（对应 `manifest.json`）。
